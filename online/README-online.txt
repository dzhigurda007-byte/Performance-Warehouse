PERFORMANCE WAREHOUSE — ОНЛАЙН-СЕРВЕР СКЛАДА
=============================================

Онлайн-сервер работает в интернете: к нему подключаются телефоны, ТСД и браузеры
из любого места. Попасть на сервер можно ТОЛЬКО по приглашению. Права сотрудника
определяются ролью, указанной в приглашении (кладовщик, сотрудник, разнорабочий
и т.д.). Свободной регистрации нет.

Защита онлайн-сервера:
  • весь трафик идёт по HTTPS (сертификат Let's Encrypt выпускается автоматически);
  • первого администратора можно создать только с КОДОМ УСТАНОВКИ из журнала сервера;
  • приглашение одноразовое, действует 7 дней (срок и число использований задаются
    при создании), ссылка-приглашение — 24 случайных символа;
  • 8 неудачных попыток входа → логин блокируется на 15 минут;
  • пароли — не короче 8 символов; сеанс без активности 30 дней закрывается;
  • резервная копия базы — автоматически раз в сутки (30 последних), вручную —
    «Ещё → Разработчик» (только администратор).


ЧТО ПОНАДОБИТСЯ
---------------
1. Сервер в интернете (VPS) с Linux (Ubuntu 22.04/24.04 или Debian 12),
   1 ядро, 1 ГБ памяти, 10 ГБ диска — этого достаточно для склада.
2. Доменное имя (например sklad.vasha-firma.ru) — у регистратора домена создайте
   A-запись, указывающую на IP-адрес VPS.
3. Открытые порты 80 и 443 на VPS.


УСТАНОВКА (около 10 минут)
--------------------------
1. Подключитесь к VPS по SSH и установите Docker:
     curl -fsSL https://get.docker.com | sh

2. Скопируйте на VPS папку из архива PerformanceWarehouse-Online.zip
   (например, в /opt/warehouse) и перейдите в неё:
     cd /opt/warehouse

3. Создайте файл настроек:
     cp .env.example .env
     nano .env
   Укажите DOMAIN (ваш домен) и EMAIL. Сохраните (Ctrl+O, Enter, Ctrl+X).

4. Запустите:
     docker compose up -d --build

5. Посмотрите код установки:
     docker compose logs warehouse | grep "КОД УСТАНОВКИ"
   (код также лежит в файле data/setup-code.txt)

6. Откройте в браузере https://ВАШ-ДОМЕН — появится создание администратора.
   Введите логин, ФИО, пароль (от 8 символов) и КОД УСТАНОВКИ.
   После этого код удаляется — второго администратора таким способом не создать.


ПОДКЛЮЧЕНИЕ СОТРУДНИКОВ
-----------------------
1. Администратор или руководитель: «Ещё → Приглашения» → выбрать роль (и отдел,
   руководителя) → «Создать». Появится ссылка и QR-код.
2. Отправьте ссылку сотруднику (мессенджер, почта) или покажите QR.
3. Сотрудник:
   • на ПК — открывает ссылку в браузере;
   • на телефоне / ТСД — устанавливает приложение (APK можно скачать со страницы
     сервера: https://ВАШ-ДОМЕН/download/PerformanceWarehouse.apk), на экране
     подключения вводит адрес «ВАШ-ДОМЕН» и сканирует QR-приглашение или
     открывает ссылку.
4. Сотрудник придумывает логин и пароль — и попадает в систему с ролью из
   приглашения. Повторно по той же ссылке зарегистрироваться нельзя.

В приложении адрес можно вводить без https:// — доменное имя открывается
по HTTPS автоматически.


ОБНОВЛЕНИЕ
----------
Скачайте новый PerformanceWarehouse-Online.zip, замените в папке на VPS всё,
КРОМЕ папки data и файла .env, и выполните:
     docker compose up -d --build
База обновится сама при запуске.


РЕЗЕРВНЫЕ КОПИИ И ВОССТАНОВЛЕНИЕ
--------------------------------
База: data/warehouse.db. Копии: data/backups/.
Рекомендуется периодически скачивать data/backups на другой компьютер.
Восстановление:
     docker compose stop warehouse
     cp data/backups/НУЖНАЯ-КОПИЯ.db data/warehouse.db
     docker compose start warehouse


ДРУГИЕ ВАРИАНТЫ
---------------
• Сервер на ПК склада + доступ из интернета: нужен «белый» IP у интернет-провайдера,
  проброс порта 443 на ПК в роутере и HTTPS. Запуск сервера на ПК в онлайн-режиме:
     node pw-server.cjs --online --public-url https://ВАШ-ДОМЕН --tls-cert cert.pem --tls-key key.pem --port 443
  Сертификат и ключ (PEM) нужно получить у удостоверяющего центра или через Let's Encrypt.
  Вариант с VPS проще и надёжнее: не зависит от ПК склада и домашнего интернета.

• Без HTTPS сервер в интернет выставлять НЕЛЬЗЯ: пароли и данные склада
  передавались бы открытым текстом.


ПАРАМЕТРЫ СЕРВЕРА (для опытных)
-------------------------------
  --online / PW_ONLINE=1             онлайн-режим (код установки, лимиты, без CORS)
  --public-url / PW_PUBLIC_URL       адрес в интернете (для ссылок-приглашений)
  --tls-cert, --tls-key              встроенный HTTPS (пути к PEM-файлам)
  --trust-proxy / PW_TRUST_PROXY=1   сервер за Caddy/nginx (IP клиента из X-Forwarded-For)
  --setup-code / PW_SETUP_CODE       свой код установки
  --port / PW_PORT, --data / PW_DATA, --web / PW_WEB

PERFORMANCE WAREHOUSE — ОНЛАЙН-СЕРВЕР НА ХОСТИНГЕ С ISPmanager (reg.ru и др.)
============================================================================

Это вариант без Docker: файлы загружаются через файловый менеджер ISPmanager,
сервер запускается как приложение Node.js. Вход — только по приглашениям,
права — по роли из приглашения.


0. СНАЧАЛА ПРОВЕРЬТЕ ТАРИФ
--------------------------
Сервер склада — это постоянно работающая программа на Node.js (не PHP-сайт).
Ему нужна версия Node.js 22.13 или новее.

  • VPS / «Облачный сервер» с ISPmanager — подходит.
  • Виртуальный хостинг — подходит, ТОЛЬКО если в ISPmanager для сайта можно
    включить Node.js и выбрать версию 22. Если в настройках сайта нет Node.js
    или есть только старые версии (16, 18, 20) — напишите в поддержку (текст ниже)
    или используйте VPS.

Текст для поддержки reg.ru (можно скопировать):
  «Здравствуйте! Нужно запустить на домене ВАШ-ДОМЕН приложение Node.js:
   файл запуска app.js, версия Node.js 22.13 или новее, постоянная работа
   процесса, проксирование всех запросов домена на приложение, SSL Let's Encrypt.
   Подскажите, доступно ли это на моём тарифе и как включить?»


1. ЗАГРУЗКА ФАЙЛОВ
------------------
1. В ISPmanager откройте «Менеджер файлов».
2. Создайте папку для приложения ВНЕ папки сайта, например:
     /var/www/ВАШ-ЛОГИН/data/warehouse-app
   (если панель разрешает приложение только в папке сайта — используйте её,
   база всё равно будет храниться уровнем выше, см. dataDir).
3. Загрузите туда архив PerformanceWarehouse-Hosting.zip и распакуйте его
   (в менеджере файлов: выделить архив → «Извлечь»).
   В папке должны оказаться: app.js, pw-server.cjs, pw-config.json, web/, .htaccess.


2. НАСТРОЙКА
------------
Откройте pw-config.json (в менеджере файлов → «Редактировать») и укажите:

  "publicUrl":  "https://ВАШ-ДОМЕН"     — адрес, по которому будут заходить сотрудники
  "dataDir":    "../pw-data"            — где хранить базу (папка создастся сама;
                                          должна быть ВНЕ папки сайта)
  "port":       3000                    — порт приложения (если панель назначает порт
                                          сама — он важнее этого значения)
  "host":       "127.0.0.1"             — не менять (снаружи доступ только через HTTPS панели)
  "setupCode":  ""                      — можно задать свой код установки администратора

Остальное не трогайте. Сохраните файл.


3. ЗАПУСК ПРИЛОЖЕНИЯ NODE.JS
----------------------------
В ISPmanager (названия пунктов зависят от версии панели):
  «Сайты» → выберите ВАШ-ДОМЕН → «Изменить» / «Настройки» → раздел Node.js:
    • включить Node.js для сайта;
    • версия Node.js: 22 (или новее);
    • папка приложения: папка из шага 1;
    • файл запуска (startup file): app.js;
    • режим: проксирование всех запросов сайта на приложение (порт из pw-config.json,
      если панель спрашивает порт);
  сохранить и запустить / перезапустить приложение.

На VPS без раздела Node.js в панели — можно запустить через SSH:
    cd /var/www/ВАШ-ЛОГИН/data/warehouse-app
    node app.js
  а для постоянной работы — службой systemd (см. раздел «Для VPS» ниже).


4. HTTPS (обязательно)
----------------------
ISPmanager → «SSL-сертификаты» → «Создать» → Let's Encrypt → ВАШ-ДОМЕН.
Включите для сайта «Перенаправлять HTTP на HTTPS».
Без HTTPS работать через интернет нельзя: пароли передавались бы открытым текстом.


5. ПЕРВЫЙ ВХОД
--------------
1. Узнайте КОД УСТАНОВКИ — он в файле pw-data/setup-code.txt (менеджер файлов)
   и в журнале приложения Node.js.
2. Откройте https://ВАШ-ДОМЕН — появится создание администратора.
   Введите КОД УСТАНОВКИ, логин, ФИО и пароль (от 8 символов).
3. Пригласите сотрудников: «Ещё → Приглашения» → роль → «Создать ссылку».
   На телефоне: приложение → «Сервер склада» → адрес ВАШ-ДОМЕН (без https://) →
   отсканировать QR-приглашение. APK: https://ВАШ-ДОМЕН/download/PerformanceWarehouse.apk


ОБНОВЛЕНИЕ
----------
Загрузите новый PerformanceWarehouse-Hosting.zip, распакуйте с заменой файлов
(pw-config.json и папку pw-data НЕ заменять) и перезапустите приложение в панели.
База обновится сама.


РЕЗЕРВНЫЕ КОПИИ
---------------
pw-data/warehouse.db — база, pw-data/backups/ — ежедневные копии (30 последних).
Периодически скачивайте pw-data/backups через менеджер файлов к себе.


ЕСЛИ НЕ ЗАПУСКАЕТСЯ
-------------------
Журнал приложения (в панели или файл журнала Node.js) подскажет причину:
  • «нужна версия Node.js 22.13 или новее» — выберите Node.js 22 для сайта;
  • «Ошибка в pw-config.json» — проверьте кавычки и запятые в файле;
  • «EADDRINUSE» — порт занят: укажите другой "port" в pw-config.json и в панели.


ДЛЯ VPS: ПОСТОЯННАЯ РАБОТА ЧЕРЕЗ SYSTEMD (по SSH, от root)
---------------------------------------------------------
Файл /etc/systemd/system/warehouse.service:

  [Unit]
  Description=Performance Warehouse
  After=network.target

  [Service]
  WorkingDirectory=/var/www/ВАШ-ЛОГИН/data/warehouse-app
  ExecStart=/usr/bin/node app.js
  Restart=always
  User=ВАШ-ЛОГИН

  [Install]
  WantedBy=multi-user.target

Затем:  systemctl daemon-reload && systemctl enable --now warehouse
В ISPmanager для сайта настройте проксирование на http://127.0.0.1:3000.

# Performance Warehouse

Мобильное приложение (iOS / Android) для адресного складского учёта ТМЦ
по схеме **Склад → Стеллаж → Ячейка → (Короб) → Товар** с маркировкой QR-кодами.

## Возможности

- **Аккаунты** — регистрация по логину и паролю (без e-mail и подтверждений), автор и
  исполнитель фиксируются в каждом документе.
- **Структура склада** — склады, стеллажи, ячейки (массовое создание «ярус × место»),
  короба внутри ячеек. В одной ячейке — любое количество товаров и коробов.
- **Номенклатура** — артикул, наименование, единица, штрихкод производителя, остатки по
  местам хранения, история движений.
- **QR-маркировка** — QR для ячеек, коробов и товаров; печать этикеток (по одной или
  массово на стеллаж/склад); поиск чего угодно сканированием.
- **Приходный ордер** — сканируем/выбираем место (ячейку или короб), затем товары.
- **Расходный ордер по заявке** — указываем, что выдать; система подбирает места по FIFO
  и печатает ордер с адресами (лист подбора).
- **Расходный ордер по факту** — сканируем короб (или ячейку) и изымаем товар из списка
  содержимого, либо сразу сканируем товар — сканировать короб не обязательно.
- **Перемещение короба** между ячейками.
- **История ТМЦ** — кто, когда, что, откуда и кому выдал; фильтры и поиск.
- Проведение / отмена проведения документов (как в 1С), контроль отрицательных остатков.

Подробное обоснование архитектуры и сравнение с 1С / WMS / МойСклад —
в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Запуск

```bash
npm install
npx expo start           # затем: a — Android, i — iOS, w — браузер
```

Модули камеры, SQLite и печати входят в Expo Go, поэтому приложение можно открыть
на телефоне через **Expo Go** по QR-коду из терминала. Сборка установочных файлов:

```bash
npx eas-cli@latest build -p android --profile preview   # APK
npx eas-cli@latest build -p ios
```

## Проверки

```bash
npm run typecheck   # TypeScript (приложение + тесты)
npm test            # бизнес-логика на реальном SQLite: приход, расход, FIFO, перемещение, отмена
```

## Структура

```
src/
  app/                 экраны (Expo Router)
    (tabs)/            Операции · Склад · Товары · Документы · История
    warehouse/ rack/ cell/ box/ item/ doc/
    login.tsx
  components/          UI-кит, сканер, QR, диалоги выбора (товар, место, остаток, количество)
  db/                  схема и миграции, репозиторий (запросы и проведение), авторизация
  domain/              чистая логика: форматы QR-кодов, FIFO-подбор, типы
  lib/                 печать этикеток и ордеров, контекст авторизации
tests/                 node:test
docs/ARCHITECTURE.md
```

## Быстрый старт в приложении

1. Зарегистрируйтесь.
2. «Склад» → «Новый склад» → добавьте стеллаж → «Создать» ячейки сеткой →
   «Печать QR ячеек стеллажа» и наклейте этикетки.
3. «Товары» → «Новый товар» (можно отсканировать штрихкод производителя).
4. «Операции» → «Приходный ордер» → «Сканировать»: QR ячейки/короба, затем товары → «Провести».
5. Выдача: «Расходный ордер (заявка)» или «Расход по факту» → получатель → «Провести».
